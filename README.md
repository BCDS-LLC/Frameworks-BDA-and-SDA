# BC-DS Framework Papers: BDA v2.1 and SDA v1.0

By Monica M. Hernandez and Daniel A. Montero, BC-DS (Business Consultants for Digital Solutions, LLC), Rockville, Maryland.

This repository holds two framework papers as BC-DS first published them here, between 17 March and 3 April 2026:

* **Business Decision Architecture (BDA): A System Architecture for Decision-Making in the Age of AI**, version 2.1, March 2026, with its appendices B and C. Monica M. Hernandez and Daniel A. Montero are its co-authors.
* **Solo Decision Architecture (SDA) Framework: An Operating System Powered by the Dual Lens Principle**, version 1.0, March 2026. Monica M. Hernandez is its primary author, with Daniel A. Montero as co-author.

The site [frameworks.bc-ds.com](https://frameworks.bc-ds.com/) is built from this repository by Netlify. The build now live was published on 3 April 2026 at 21:58:34 UTC from commit a8b735b.

The current versions are on Zenodo:

* **BDA v3.0**, *Business Decision Architecture (BDA) Framework: The Discipline of Organizational Decision Governance*, 30 April 2026: [doi.org/10.5281/zenodo.19903175](https://doi.org/10.5281/zenodo.19903175)
* **SDA v2.0**, *Solo Decision Architecture (SDA) Framework*, 29 April 2026: [doi.org/10.5281/zenodo.19871192](https://doi.org/10.5281/zenodo.19871192)

The first version of the BDA framework, v1.00 of 26 February 2026, is in [Daniel-ams/BDA-Framework-v-1.00](https://github.com/Daniel-ams/BDA-Framework-v-1.00).

## How to check the dates

1. **The files.** Compute each PDF's SHA-256, with `shasum -a 256 <file>` on a Mac or `sha256sum <file>` elsewhere, and compare it with the table above.
2. **The commits.** Every commit up to 2026-04-03 was made through GitHub's web pages, and GitHub signed each one and marks it Verified in the repository's history.
